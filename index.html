Concept

How Trickplayer Works

Instead of streaming bandwidth-heavy video feeds, Trickplayer plays video using assets your media server already creates for fast-forward scrub previews.

01

Trickplay Stills

Plex and Jellyfin generate thumbnail indexes (BIF files or tile sheets) for visual scrubbing. Trickplayer uses these lightweight still frames as the visual track of your media.

02

Subtitle Timing

By reading the subtitle track, Trickplayer matches each line of spoken dialogue with the video still captured at that exact timestamp.

03

Dialogue-Paced Playback

The player steps through scenes at the pace of the conversation. You get the story, the acting, and the visual context on displays where video is normally impossible.

Supported Servers

Plex & Jellyfin Support

Trickplayer connects directly to your personal home media server. Each server brings unique advantages to the playback experience.

Account Discovery

Plex

Plex provides a streamlined one-time PIN sign-in that gives you access to your entire server ecosystem with a single login.

  • ✓ Multi-Server Access: Sign in once with your Plex account to discover and switch between all of your local, remote, and shared servers.
  • ✓ Fast and Efficient: Uses Plex's BIF trickplay files with 2-second thumbnail intervals and efficient downloads (enable Generate video preview thumbnails under Scheduled Tasks).
  • ✓ Embedded & External Subtitles: External .srt files play immediately, while embedded text tracks inside video files can be extracted and cached on first play.
  • ✓ In-App Subtitle Search: Use Find Subtitles to search OpenSubtitles through the native Plex search.
Open Media System

Jellyfin

Jellyfin provides native embedded subtitle serving and connects directly to your self-hosted server with Quick Connect sign-in.

  • ✓ Embedded Subtitle Support: Jellyfin converts and serves embedded text subtitles on demand, so items with embedded tracks play immediately without an extraction step.
  • ✓ In-App Subtitle Search: Supports Find Subtitles right from the app using your Jellyfin server's configured subtitle plugin.
  • ✓ Trickplay Tile Grids: Reads Jellyfin's trickplay tile sheets directly (enable Trickplay image extraction in library settings). Defaults to 10-second intervals, which can be lowered in system.xml for a smoother experience.
  • • Local & Tailscale Connection: Because Jellyfin has no central relay domain like plex.direct, connect over your local network or remotely via a Tailscale address (e.g. https://[your-jellyfin-server].ts.net).

Privacy By Design

Your media stays between you and your server.

Trickplayer has no cloud servers or intermediate proxies. All network requests go straight from your device to your personal media server.

🔒

Direct Connection

Tokens, passwords, and media content are exchanged directly with your Plex or Jellyfin server over your local network or personal domain.

🚫

Zero Trickplayer Servers

We operate no backend servers, collect no telemetry, and store no user analytics or watch logs.

💻

In-Browser Preview Player

The web preview player runs entirely within your browser runtime using client-side canvas and scripts.

🤝

Open Source

Released platform codebases are available on GitHub for open review and community contributions.

FAQ

Frequently Asked Questions

Is this streaming video to my glasses?

No — and it can't be. The link carries a few kilobytes a second, and the display is monochrome green. Trickplayer sends one still every few seconds, using the preview thumbnails your server already generated. Think motion comic, not film.

Why does an item say it can't be played?

It is missing one of the two halves. Trickplayer needs preview thumbnails (a trick-play index) and text subtitles for the same item. Every episode is listed, and the badges say which half each one has:

Badge Meaning
SUBS in green Subtitles ready. Plays straight away.
SUBS in amber Subtitles are inside the video file. Its page offers Extract (read them out through your server, once) or Download (search for a subtitle file). After either, it's green.
SUBS in red Plex lists a subtitle file that isn't on the server any more. Use Find subtitles, or refresh the item's metadata in Plex.
SUBS in grey No text subtitles. Image-based ones (PGS, VobSub), styled ASS tracks and forced-only tracks don't count. Use Find subtitles to get some.
IMG in grey No preview thumbnails yet. That one has to be fixed on the server — see Supported Servers.
What's the difference between Extract and Download?

Plex won't hand over a subtitle track embedded inside a video file directly, only sidecar files sitting next to it. Extract asks your server's transcoder to read the track out, which means the server runs through the whole file once: a few seconds to a couple of minutes depending on the video and the server's hardware. The progress bar shows an estimate of the time left once it knows the pace, and Cancel stops the work on the server. Your phone downloads only the subtitles themselves (tens of kilobytes), and the result is kept, so playing the item again is instant. The subtitles are the file's own, so they're in sync with it.

Download searches for a subtitle file instead, through your media server, and is quicker for a long video or a slow server. The file comes from a third party, so its timing may differ from your copy — see below.

Extraction reads the track that is selected for the item in Plex; to change the language, pick the subtitle track in a Plex app first. Jellyfin serves embedded tracks on its own, so items there never need extracting.

Where do downloaded subtitles come from?

From your media server's own subtitle search — on Plex, the OpenSubtitles agent built into the server; on Jellyfin, a subtitle plugin. Trickplayer only asks the server to search and to download the one you pick: the server contacts OpenSubtitles, fetches the file and attaches it to the item, so it's then there for every app that plays from your server. The file never passes through your phone.

Results list the release each file was made for, and are ordered best first: files the search matched to your exact video, then plain subtitles before ones that describe sounds (SDH), then the most downloaded. A file whose name is for a different episode is marked and moved to the bottom, even when the search calls it a match — that happens. Pick the one whose release looks like your copy; if its timing is off, search again and pick another.

What's the catch with Jellyfin?

Remote access. Glasses apps declare in advance which domains they may reach, and Plex has a first-party one (plex.direct) that covers every user's server. Jellyfin has no equivalent, so there is no single domain to declare.

Local connections work. For remote access, Trickplayer also permits *.ts.net, so a Tailscale network will reach your server from anywhere. Anything else is currently out of reach.

How do I shorten the time between frames in Jellyfin?

Jellyfin defaults to generating trickplay images every 10 seconds (10000 ms). To shorten the interval between frames, edit your Jellyfin server's system.xml configuration file and decrease the <Interval> value inside <TrickplayOptions> (for example, 5000 for 5 seconds): 

<TrickplayOptions>
    <EnableHwAcceleration>false</EnableHwAcceleration>
    <EnableHwEncoding>false</EnableHwEncoding>
    <EnableKeyFrameOnlyExtraction>false</EnableKeyFrameOnlyExtraction>
    <ScanBehavior>NonBlocking</ScanBehavior>
    <ProcessPriority>BelowNormal</ProcessPriority>
    <Interval>5000</Interval>
    <WidthResolutions>
      <int>320</int>
    </WidthResolutions>
    <TileWidth>10</TileWidth>
    <TileHeight>10</TileHeight>
    <Qscale>4</Qscale>
    <JpegQuality>90</JpegQuality>
    <ProcessThreads>1</ProcessThreads>
  </TrickplayOptions>
The picture got blocky mid-episode. Is something broken?

No — that's the quality ladder doing its job. When sends slow down or fail, the picture steps down to something cheaper so frames keep arriving rather than stopping, then climbs back on its own once the link recovers. Locking your phone is the most common cause: it slows Bluetooth enough to push full-size frames past the host's deadline.

Does it send my viewing data anywhere?

No. It talks to your media server and nothing else. There is no account, no telemetry and no analytics. If you turn on Report progress, positions are written to your server — the same thing any other client does — and nowhere else.

Why is the brightest part of the picture uncomfortable?

The display's top level reads much brighter than its position in the range suggests, which on a see-through display can cause eye strain. The Glare setting gives up the brightest levels to soften it. It is off by default; the first two steps cost roughly half a percent of the picture.
